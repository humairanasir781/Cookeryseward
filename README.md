**The Cookeryseward Website**

A modern, high-end restaurant website design built with pure HTML, CSS, and minimal JavaScript. This project showcases a luxury dining experience with a strong focus on visual storytelling, smooth animations, and conversion-focused UI.

✨ **Overview**

**Live Preview:** https://humairanasir781.github.io/Cookeryseward/

This is a fully responsive, single-page restaurant website designed to represent a premium seafood and oyster bar brand. The layout emphasizes elegance, readability, and user engagement.

The design includes:

Smooth scroll animations

Modern typography pairing

Minimal, premium color palette

Mobile-first responsive layout

Conversion-focused call-to-actions

🎨 **Design Features**

Elegant typography using Playfair Display, Cormorant Garamond, and DM Sans

Dark luxury theme with gold accents

Smooth reveal animations using Intersection Observer

Custom hero section with animated background
